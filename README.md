# Тести НМТ з математики

Тести для підготовки до НМТ з математики, розроблені на **Next.js (React)**.

## Можливості

- **Повний тест НМТ** — 22 завдання з усіх тем, як на реальному іспиті.
- Завдання охоплюють усі теми програми: числа і вирази, рівняння і нерівності, функції, геометрія, ймовірність і статистика, текстові задачі.
- Кожне завдання має чотири варіанти відповіді (А–Г), як на НМТ.
- Проходження як на реальному іспиті: без підказок, можна ходити між завданнями і змінювати відповіді.
- Після завершення — результат, аналіз помилок за темами та розбір кожного завдання з поясненням розв'язання.

## Технології

- Next.js 14 (App Router)
- React 18
- TypeScript
- Банк із 121 завдання — у `src/data/questions.ts`

## Локальний запуск

```bash
npm install
npm run dev
```

Відкрий [http://localhost:3000](http://localhost:3000).

## Збірка для продакшену

```bash
npm run build
npm run start
```

## Деплой на Vercel

1. Запушуй репозиторій на GitHub.
2. На [vercel.com](https://vercel.com) увійди через «Continue with GitHub».
3. **Add New → Project** → обери репозиторій `nmt-test` → **Import**.
4. Нічого не змінюй (Next.js визначається автоматично) → **Deploy**.
5. Готово: посилання виглядає як `https://nmt-test-<id>.vercel.app`.
