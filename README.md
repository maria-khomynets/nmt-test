# Тренажер НМТ з математики

Інтерактивний тренажер для підготовки до НМТ з математики, розроблений на **Next.js (React)**.

## Можливості

- **Повний тест НМТ** — 22 завдання з усіх тем, таймер 120 хвилин, як на реальному іспиті.
- **Тренування по темах** — вибір окремої теми (без таймера):
  - Числа і вирази
  - Рівняння і нерівності
  - Функції
  - Геометрія
  - Ймовірність і статистика
  - Текстові задачі
- Завдання у форматі НМТ: вибір одного з п'яти варіантів (А–Д) або введення числової відповіді.
- Миттєва перевірка, пояснення розв'язання та розбір помилок після тесту.

## Технології

- Next.js 14 (App Router)
- React 18
- Банк із 121 завдання — у `src/data/questions.js`

## Локальний запуск

```bash
npm install
npm run dev
```

Відкрий [http://localhost:3000](http://localhost:3000).

## Збірка для продакшену

```bash
npm run build
npm run start
```
