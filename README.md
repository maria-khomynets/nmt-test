# Тести НМТ з математики

Тестувальник для підготовки до НМТ з математики, розроблений на **Next.js 14 (React, TypeScript)**.

## Можливості

- **Вибір теми** — dropdown з 6 тем або «Усі теми».
- **Налаштування кількості** — від 1 до 121 завдання.
- **Проходження як на НМТ** — без підказок, можна ходити назад/далі і змінювати відповіді.
- **Live-статистика** — правильні відповіді, час, середній час відповіді оновлюються в реальному часі.
- **Результат** — бал, порівняння з бенчмарком, аналіз помилок за темами, розбір кожного завдання з поясненням.
- **121 завдання** з 4 варіантами відповіді (А–Г), як на реальному НМТ.

## Технології

- Next.js 14 (App Router)
- React 18
- TypeScript 5.6.3
- CSS-змінні (бірюзова тема)

## Як працює потік даних

1. **Старт**: користувач обирає тему + кількість → `page.tsx` фільтрує і перемішує питання → `Quiz`.
2. **Тест**: `Quiz` зберігає відповіді в `choices[]`, показує live-статистику, таймер.
3. **Завершення**: `Quiz` формує `QuizResult { answers, totalTime }` → `page.tsx` передає в `Result`.
4. **Результат**: `ResultScore` рахує бал, `ResultTopicAnalysis` — помилки за темами, `ResultReview` — розбір.

## Локальний запуск

```bash
npm install
npm run dev
```

Відкрий [http://localhost:3000](http://localhost:3000).

## Збірка для продакшену

```bash
npm run build
npm run start
```

## Деплой на Vercel

1. Запушуй репозиторій на GitHub.
2. На [vercel.com](https://vercel.com) увійди через «Continue with GitHub».
3. **Add New → Project** → обери репозиторій `nmt-test` → **Import**.
4. Нічого не змінюй (Next.js визначається автоматично) → **Deploy**.
5. Готово: посилання виглядає як `https://nmt-test-<id>.vercel.app`.
