# Тести НМТ з математики

Тести для підготовки до НМТ з математики, розроблені на **Next.js (React)**.

## Можливості

- **Повний тест НМТ** — 22 завдання з усіх тем, таймер 120 хвилин, як на реальному іспиті.
- **Тест по темах** — перевірка знань з окремої теми (без таймера):
  - Числа і вирази
  - Рівняння і нерівності
  - Функції
  - Геометрія
  - Ймовірність і статистика
  - Текстові задачі
- Кожне завдання має чотири варіанти відповіді (А–Г), як на НМТ.
- Миттєва перевірка, пояснення розв'язання та розбір помилок після тесту.

## Технології

- Next.js 14 (App Router)
- React 18
- Банк із 121 завдання — у `src/data/questions.js`
## Локальний запуск

```bash
npm install
npm run dev
```

Відкрий [http://localhost:3000](http://localhost:3000).

## Збірка для продакшену

```bash
npm run build
npm run start
```
