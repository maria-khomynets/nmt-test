# Тестувальник НМТ з математики

Вебдодаток для підготовки до Національного мультипредметного тесту (НМТ) з математики. Розроблений на **Next.js 14** з використанням **React 18** та **TypeScript**.

---

## Можливості додатку

### Вибір теми та кількості завдань
На стартовому екрані користувач бачить випадаючий список (dropdown) з 6 темами програми НМТ з математики, а також опцію «Усі теми». Після вибору теми можна вказати кількість завдань від 1 до 121 (максимальна кількість у банку). Далі — натиснути кнопку «Старт».

### Шість тем програми
1. Числа і вирази (дроби, степені, корені, відсотки, властивості чисел)
2. Рівняння і нерівності (лінійні, квадратні рівняння, системи, нерівності)
3. Функції (графіки, області визначення, властивості функцій)
4. Геометрія (планіметрія, стереометрія, тригонометрія, об'єми)
5. Ймовірність і статистика (класична ймовірність, комбінаторика, статистика)
6. Текстові задачі (рух, робота, суміші, відсоткові задачі)

### Формат проходження як на реальному НМТ
- Під час тесту **немає підказок** — користувач не знає, чи правильна відповідь, поки не завершить тест.
- Кожне завдання має **чотири варіанти відповіді** (А, Б, В, Г), як на справжньому НМТ.
- Можна **ходити між завданнями** кнопками «Назад» і «Далі», змінюючи відповіді.
- Питання без відповіді зараховуються як помилка.

### Live-статистика під час тесту
Під варіантами відповідей у реальному часі оновлюється панель з трьома показниками:
- **Правильних відповідей**: скільки правильних зі скількох відповіли.
- **Час**: загальний час проходження тесту в секундах.
- **Середній час відповіді**: середній час на одне завдання.

Таймер оновлюється кожну секунду. Статистика з'являється з першого питання.

### Результат після завершення
Після натискання кнопки «Завершити тест» користувач бачить:

1. **Бал** — великий відсоток правильних відповідей.
2. **Статистику** — кількість правильних відповідей, середній час відповіді, порівняння з бенчмарком.
3. **Аналіз помилок за темами** — прогрес-бари для кожної теми: де були помилки, де все правильно.
4. **Розбір кожного завдання** — текст питання, ваша відповідь, правильна відповідь, пояснення розв'язання.

### 121 завдання в банку
Банк завдань містить 121 питання з різними темами та рівнями складності. Розподіл за темами:
- Числа і вирази — 21 завдання
- Рівняння і нерівності — 20 завдань
- Функції — 20 завдань
- Геометрія — 20 завдань
- Ймовірність і статистика — 20 завдань
- Текстові задачі — 20 завдань

## Опис кожного компонента

### StartScreen.tsx
Стартовий екран додатку. Містить:
- **Випадаючий список (dropdown)** з темами. Опція «Усі теми» за замовчуванням. Поруч з кожною темою показується кількість завдань у дужках.
- **Поле введення кількості** завдань (число від 1 до максимального для обраної теми). За замовчуванням — 10.
- **Кнопка «Старт»** — запускає тест з обраними параметрами.

### Quiz.tsx (оркестратор)
Головний компонент тесту. Керує:
- **Станом**: номер поточного завдання, вибрані відповіді (`choices[]`), загальний час.
- **Таймером**: оновлює `elapsed` кожну секунду через `setInterval`.
- **Логікою завершення**: формує `QuizResult { answers, totalTime }` і передає вгору.

### QuizHeader.tsx
Показує:
- Рядок «Завдання X з Y» та «Відповідей: X».
- Прогрес-бар (заповнюється від 0% до 100%).

### QuizQuestion.tsx
Рендерить:
- Текст питання.
- Сітку з 4 варіантами відповідей (2×2 на десктопі, 1 колонка на мобільних).
- Кожен варіант — кнопка з літерою (А, Б, В, Г) та текстом відповіді.
- Обраний варіант підсвічується кольором теми.

### QuizLiveStats.tsx
Панель з live-статистикою:
- **Правильних відповідей**: X з Y.
- **Час**: загальний час проходження тесту.
- **Середній час відповіді**: час ділиться на кількість відповідей.

### QuizNav.tsx
Навігація та завершення:
- Кнопки **«Назад»** і **«Далі»** для переходу між завданнями.
- **Попередження** про кількість завдань без відповіді.
- Кнопка **«Завершити тест»** з підтвердженням, якщо є пропущені питання.

### Result.tsx (оркестратор)
Обчислює загальний бал, рівень оцінки (відмінно/добре/задовільно/треба повторити) і рендерить три секції: `ResultScore`, `ResultTopicAnalysis`, `ResultReview`.

### ResultScore.tsx
Показує:
- Великий відсоток правильних відповідей.
- Кількість правильних відповідей (X з Y).
- Порівняння з бенчмарком («Краще ніж X%»).
- Середній час відповіді.
- Кнопки **«Пройти ще раз»** (повернення на старт) і **«На головну»** (очищення стану).

### ResultTopicAnalysis.tsx
Для кожної теми показує:
- Назву теми з емодзі.
- Кількість помилок (X / Y) або «Без помилок».
- Прогрес-бар: зелений (без помилок) або червоний (з помилками).

### ResultReview.tsx
Розбір кожного завдання:
- Текст питання з бейджем (✓ або ✗).
- Ваша відповідь або «Не відповіли».
- Правильна відповідь (якщо помилка).
- Тема завдання та пояснення розв'язання.

## Як працює потік даних

```
Старт → Quiz → Результат
```

1. **Старт**: користувач обирає тему та кількість → `page.tsx` фільтрує питання за темою, перемішує через `shuffle()`, бере потрібну кількість → створює `quizQuestions`.

2. **Тест**: компонент `Quiz` отримує `quizQuestions`. Зберігає вибрані відповіді в масив `choices[]` (індекс = номер завдання, значення = номер варіанта або `null`). Таймер працює через `setInterval`. Live-статистика рахує `correctCount` і `avgTime` на кожному рендері.

3. **Завершення**: при натисканні «Завершити тест» формується `QuizResult { answers: AnswerRecord[], totalTime: number }`. `AnswerRecord` містить питання, вибрану відповідь, правильність.

4. **Результат**: `page.tsx` передає `result` у `Result`. `ResultScore` рахує відсоток. `ResultTopicAnalysis` групує помилки за темами. `ResultReview` показує кожне завдання з поясненням.

## Типи даних (types.ts)

| Тип | Опис |
|---|---|
| `TopicId` | Union-тип: `'numbers' \| 'equations' \| 'functions' \| 'geometry' \| 'probability' \| 'word'` |
| `Level` | Рівень складності: `'easy' \| 'medium' \| 'hard'` |
| `Topic` | Тема: `id`, `title`, `description`, `color`, `emoji` |
| `Question` | Завдання: `id`, `topic`, `level`, `type` (завжди `'choice'`), `question`, `options` (4 рядки), `answer` (0–3), `explanation` |
| `AnswerRecord` | Запис відповіді: `question`, `chosen` (номер або `null`), `correct` (boolean) |
| `QuizResult` | Результат тесту: `answers` (масив `AnswerRecord`), `totalTime` (секунди) |
